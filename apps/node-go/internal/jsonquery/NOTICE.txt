Six production Go files are copied into evaluator/. Local changes add the
finite-intermediate result profile, error-aware matcher continuations, guarded
sort invocation/truthiness, native signature checks and explicit matcher
callability metadata. R6 also retains native partial/context metadata, original
match objects and capture slots, corrects fractional/empty-input matcher calls,
and replaces an allocating length count with the same UTF-8 codepoint count.
Added source files are finite.go, callbacks.go, matchdata.go, native.go, length.go.
evaluator/upstream.json records raw per-file SHA-256 and the exact unified patch.
evaluator/LICENSE preserves the upstream LICENSE bytes without modification.
The application wrapper also supplies its fixed per-expression numeric shim.
